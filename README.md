# SavingsVault – Automated Savings & Interest Accumulation
SavingsVault enables users to store STX securely while earning periodic interest, providing a simple on-chain savings product with transparent balance growth.

## Core Capabilities
- Secure deposits and withdrawals anytime
- Automated interest accrual on user balances
- Individual savings position tracking
- Non-custodial access to stored funds

## Key Functions
deposit, withdraw, distribute-interest, balance-of, get-total-saved
